# IA qui répond aux questions

Ce dépôt contient une petite intelligence artificielle en Python qui répond à des questions simples en français.

## Fonctionnalités

- Salutations (`bonjour`, `salut`)
- Date et heure
- Présentation de l'assistant
- Calculs simples (`+`, `-`, `*`, `/`)

## Lancer

```bash
python3 ia_questions.py
```

Puis pose des questions comme:

- `Bonjour`
- `Quelle heure est-il ?`
- `Quelle est la date ?`
- `Combien font 25 * 4 ?`

Quitter avec `quit`.
